# 归墟奈亚拉托提普链接

<ItemLink id="gt_shanhai:nyarlathoteps_tentacle_preview" /> 已支持实际成形与配方加工。注册 ID 保留旧名称，物品显示为“奈亚拉托提普之触”。机器支持量子化现实重构和铸币工厂，可独立运行。广播已转交 [奈亚拉托提普之回响](nyarlathoteps_echo.md)，使用新的“无貌者之音”配方类型。

奈亚使用自己的能源仓口、物品和流体仓口。连接归墟只共享现有增益与联动特效，不搬移物料，也不改由归墟供电。物质模块、线程增强和额外挂载仍按机器界面的实际配置生效；铸币继续遵守货币等级与禁用配置。

仓口只能替换控制器同一面、周围20格 `gtlcore:molecular_casing` 分子机械方块。两侧大型结构、背面和底部的机壳保持固定，不能替换仓口。旧透镜槽仅供取出已保存的透镜，请转移至回响。

## 获取与绑定

使用 <ItemLink id="gt_shanhai:guixu_hyperdimensional_link_module" /> 和末影之眼无序合成一枚 <ItemLink id="gt_shanhai:guixu_nyarlathotep_link_module" />。

1. 手持新模块，右键已成形的 <ItemLink id="gt_shanhai:guixu_vision_core" /> 记录主机。
2. 再右键已成形奈亚，完成绑定。
3. 生存模式消耗一枚模块；创造模式只清除道具记录。

两台机器可跨维度、无限距离连接，但两端所在区块必须已加载。每台归墟只能绑定一台奈亚，每台奈亚只能绑定一台归墟；这条连接与原始终焉引擎的超维度连接独立，可以同时存在。

## 暂停与解除

任一端未加载或未成形时，绑定地址保留，远端增益与通道特效暂停，奈亚恢复使用自身能力。两端恢复后自动验证双向绑定，不强制加载区块。

手持奈亚链接模块潜行右键任一绑定端点，可解除连接。解除不返还已消耗的模块；潜行右键其他方块只清除手中道具的记录。

如果另一端在解除时未加载，其旧地址会留存。可以潜行右键该端清除，也可以用新模块重新绑定原来的同一对机器修复连接；不能用残留地址覆盖其他机器的绑定。

## 黑日与黑洞

有效连接时，黑日附近出现通道，物质流从黑日进入通道，并在归墟侧通道中涌出、被黑洞吸入。跨维度只显示当前世界的端点。

这些物质流是视觉表现，不破坏世界方块，也不直接抽取远端库存或额外生成物品。归墟 AR 数据额外保留第 41 槽显示奈亚，不挤占本机 24 槽或远端引擎 16 槽。
