# 原初寰宇模拟核心
> <ItemLink id="gt_shanhai:primordial_universe_simulation_core" />\
> 处理宇宙模拟配方。沿用原初模块的通用并行、线程倍率与无线供电，不另做创世之眼或奥术星图的专属机制。

## 配方类型
* `gtceu:cosmos_simulation`：宇宙模拟。

## 安装
装在原始终焉引擎的模块位上。并行上限由物质模块槽里的模块等级决定。
