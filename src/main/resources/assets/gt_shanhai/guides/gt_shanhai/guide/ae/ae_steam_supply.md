# AE 蒸汽供应

<BlockImage id="gt_shanhai:ae_steam_binder_block" scale="5" />

这组元件让蒸汽加工机直接消耗指定 AE 网络内的蒸汽。生成端将蒸汽送入 AE，消耗端用覆盖板按加工需求取用，就像共用一座蒸汽储存站。

- 透过独立绑定方块选定 AE 网络。
- 携带已记录位置的物品绑定器，安装覆盖板时自动绑定。
- 只取用完整流体 ID **`gtceu:steam`**，保留加工机原有耗汽倍率。
- 网络离线、缺汽或目标区块未载入时停止供汽，不强制载入远方区块。

## 三个元件的用途

| 元件 | 用途 |
| --- | --- |
| <ItemLink id="gt_shanhai:ae_steam_binder_block" /> | 放置于世界并用 AE 线连上供汽网络；六面皆可接线，占用一个频道。 |
| <ItemLink id="gt_shanhai:ae_steam_binder" /> | 手持右键绑定方块，记录它的维度与座标；携带时供新覆盖板读取。 |
| <ItemLink id="gt_shanhai:ae_steam_cover" /> | 安装在消耗蒸汽的加工机、蒸汽多方块控制器或其蒸汽仓上，按需从所选网络扣汽。 |

普通蒸汽加工机，以及 GTCEu／GTL 的蒸汽多方块控制器和标准／大型蒸汽仓均有支援。每台只能安装一块这种覆盖板；多方块仍须保留原本要求的仓室与结构。

## 初次设定与自动绑定

1. 准备有电力、可用频道与 `gtceu:steam` 库存的 AE 网络。
2. 放置 <ItemLink id="gt_shanhai:ae_steam_binder_block" />，用 AE 线连上该网络。
3. 手持 <ItemLink id="gt_shanhai:ae_steam_binder" /> 右键这个绑定方块。记录完成后，物品提示会显示目标维度与座标。
4. 将记录好的物品绑定器留在物品栏或副手。
5. 把 <ItemLink id="gt_shanhai:ae_steam_cover" /> 安装到需要供汽的加工机或蒸汽仓上。新安装的覆盖板会自动复制携带物品中的记录。
6. 开启加工机，确认配方运转时 AE 蒸汽库存按原本耗汽倍率减少。

记录方块位置时可以尚未通电；实际供汽时，目标绑定方块必须仍在原位、区块已载入，而且节点与网络可用。绑定资料包含维度；跨维度使用同样受目标区块载入状态限制。

覆盖板只在加工需要时扣取蒸汽，不预先填满机器本地蒸汽槽。因此，本地槽没有增加也可能正在正常由 AE 供汽。

## 右键绑定与解除

手持物品绑定器右键覆盖板，按覆盖板当前状态切换：

| 覆盖板状态 | 右键结果 |
| --- | --- |
| 未绑定，物品已记录位置 | 绑定物品记录的目标。 |
| 已绑定 | 解除绑定。 |
| 未绑定，物品也没有记录 | 提示先右键专用绑定方块记录位置。 |

潜行右键也可以清除覆盖板绑定。**自动绑定完成后，手动右键一次就会解除**，无须再点一次确认。

要切换到另一个网络，先用物品绑定器记录新的绑定方块，再对原覆盖板右键解除、再次右键绑定新目标。重新记录物品不会直接改写已安装覆盖板的资料。

解除绑定后，已安装的覆盖板会停止供汽。需要恢复机器原本的本地蒸汽供应方式时，拆下覆盖板即可。

## 多支绑定器与保存规则

安装覆盖板时，依下列顺序取第一支有有效位置记录的物品绑定器：

1. 副手。
2. 主手。
3. 物品栏槽位顺序。

携带物品中的记录会优先于待安装覆盖板原有的绑定。若没有携带有效记录，覆盖板会保留自己已保存的绑定。想明确指定网络时，将目标绑定器放在副手即可。

物品及覆盖板都会保存绑定资料；覆盖板拆下后仍保留目标。每次供汽会读取目标方块当前所属的 AE 网络；绑定方块被拆除后，原有绑定会停止供汽。

## 排查供汽问题

- **网络有蒸汽却仍提示不足：**核对完整流体 ID 是否为 `gtceu:steam`，以及所记录方块是否接在那个网络。其他模块同名蒸汽不会被取用。
- **刚装好就不能供汽：**确认物品绑定器已有位置记录，且安装覆盖板时有携带；也可手持它右键未绑定的覆盖板补绑。
- **右键后停止供汽：**已绑定的覆盖板被切换为解除状态；再右键一次可重新绑定物品记录。
- **离开区域后停机：**检查目标绑定方块的区块是否仍载入，以及 AE 电力与频道是否正常。
- **本地蒸汽槽是空的：**直接扣 AE 库存不会预填本地槽，请观察配方进度及 AE 蒸汽库存。
- **蒸汽生成后没有进入 AE：**确认生成端输出仓或回网设备的暂存与连线。这套绑定流程负责消耗端取汽；生成端的接法见[蒸汽生成机](../machine/steam_generator.md)与[输出（回网）](output_index.md)。
