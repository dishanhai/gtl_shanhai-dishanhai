# 奈亚拉托提普之回响

<ItemLink id="gt_shanhai:nyarlathoteps_echo" /> 使用独立配方类型“无貌者之音”（`gtceu:voice_of_the_faceless`），由本机仓口提供能源、消耗品与催化剂。旧引力波天线及其配方保持原样，奈亚主机不再执行旧广播配方。

结构为13×11×15的双瓣共鸣口，共338个实体位置。前端机舱只保留四层，下方多余三层移除；控制器上移至剩余5×3接口的正中央，其余14格使用分子机械方块，可替换为本机能源、物品或流体仓口；外框的分子机械方块不能替换。超临界外壳构成主壳，配合超高密度空间弯曲机械方块、超级热容线圈、遏制场发生器、超时空装配单元、力场约束装置、中空机械方块及单个超能核心。保留聚变玻璃观察窗，移除全部海晶灯，内部空腔必须留空。

建筑文件中的1个钻石块与14个钻石矿石仅为接口占位：实际建造时分别换成回响控制器和上述分子机械方块／仓口。旧9×9×9三脚断环结构与未裁切的旧介面舱不再成型。

## 结构与仓口

JEI预览使用与实际成型一致的完整映射；只有控制器周围14格分子机械方块接受输入仓／输入舱及能源仓口，外框、线圈、场节点与核心不能替换。空腔必须保持空气。

## 远程链接

1. 使用归墟奈亚链接模块与回响碎片合成 <ItemLink id="gt_shanhai:nyarlathotep_echo_link_module" />。
2. 手持模块，右键已成形的奈亚主机记录地址，再右键已成形的回响。
3. 生存模式消耗一个模块；创造模式保留道具并清空记录。潜行右键回响解除其链接。

链路为回响 → 奈亚 → 归墟。支持跨维度，但不会强制加载任何区块。未链接时回响也可独立广播；奈亚或归墟未加载、未成形时仅降级，不删除地址或槽内透镜。

## 透镜、成本与时长

- 透镜槽始终可保存64片 `dishanhai:gravitational_lens`。独立运行或归墟离线时最多16片生效，其余保留。
- 16片及以下沿用普通广播范围与产出：无透镜×2，有透镜×3，半径最高320格。
- 奈亚与归墟链接有效时，16→64片逐步提升到最高×5产出、半径1200格。40片达到×4，64片达到×5。重叠广播取最高值，不叠乘。
- 仅回响自身的配方，消耗品与每tick耗电按有效透镜等级最高×5，耗时除以相同倍率；催化剂不会消耗或乘倍。整批EU因耗时缩短抵消每tick增长，整数取整可能产生少量差异。
- 例如基础1000tick配方，在64片模式下消耗品×5、EU/t×5，运行200tick，即10秒广播；不会仍按原50秒计时。
- 受增幅机器不会增加输入消耗，也不会套用回响自身的÷5耗时。广播只提供增产和最高50%的无损加速，离源越远加速越弱。

广播在自身配方实际成功耗电、进度前进后才生效。断电、缺料、关闭或结构失效时停止。运行中离线立即降级；加透镜或恢复链接的增幅提升从下一份已付成本的配方开始，防止低成本配方中途获得高等级效果。
