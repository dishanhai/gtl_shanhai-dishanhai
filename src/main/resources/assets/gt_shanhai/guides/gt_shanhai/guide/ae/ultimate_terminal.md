# 山海终极终端

<Column gap="15" fullWidth={true}>

<ItemImage id="gt_shanhai:ultimate_terminal" scale="4" />

<Column gap="2" fullWidth={true}>

山海终极终端是一件**多方块结构补全 / 升级 / 拆解一体化工具**：扫描任意已成型或半成型的 GTCEu 多方块控制器，自动比对结构定义算出缺失、可替换、被阻挡的位置，再从背包或绑定的 AE 网络下单补齐并一键施工；同时兼任"等级部件批量替换器"、"仓室位置高亮器"和"模块插槽检查器"。

* 材料来自玩家背包，不够时可开启 **AE 模式**改从绑定的 AE 网络下单合成，材料到齐后再确认施工。
* 施工前会做**高度合法性校验**（世界边界与 GTCEu 320 层硬上限），任何越界位置都会整体拒绝施工。
* 涉及替换/拆除现有方块的操作都需要**潜行右击二次确认**，防止误操作。

</Column>

<Column gap="2" fullWidth={true}>

## 基础操作

| 操作 | 效果 |
|---|---|
| 左击多方块控制器 | 只扫描预览（发报告 + 高亮），不消耗材料、不改变世界 |
| 右击空气 | 打开设置界面 |
| 右击非控制器方块 | 无效果；拆解模式开启时会提示"请右击对应多方块控制器" |
| 潜行右击任意方块 | 尝试把该方块绑定为 AE 网络节点；绑定失败（不是有效 ME 节点）不会报错，直接落入正常扫描/施工流程 |
| 右击多方块控制器（生存，非潜行） | 扫描并按当前状态执行：直接施工 / 武装替换确认 / 推进 AE 合成流程 |
| 潜行右击多方块控制器（生存） | 确认执行"替换类"施工，或确认"AE 材料已备齐"的最终建造 |
| 右击多方块控制器（创造模式） | 立即瞬间施工，材料凭空生成，跳过背包/AE 检查 |
| 右击多方块控制器（拆解模式开启，非潜行） | 回收整座结构 |

</Column>

<Column gap="2" fullWidth={true}>

## 扫描如何判定每个结构位置

终端会对结构定义允许的每个位置分类，报告和高亮都按这个分类来：

| 分类 | 高亮色 | 含义 |
|---|---|---|
| PLACE | 绿 | 当前是空气，且能确定要放的方块，缺料时计入施工清单 |
| REPLACE | 橙 | 当前方块属于选中的"等级方块家族"但等级不对，会被替换（需开启**功能部件替换**） |
| FORCE_REPLACE | 红橙 | 当前是不合法的挡路方块，且开启了**绝对替换模式**，会被强制拆除重放 |
| BLOCKED | 红 | 当前是不合法的挡路方块，但未开绝对替换模式，无法处理 |
| MANUAL | 白 | 当前是空气，但该位置的候选只有仓室方块或没有明确候选，必须玩家自己选择放置 |
| CHAMBER_HINT | 按仓室类型着色 | 该位置可以放某类仓室（见下方"仓室高亮"），终端默认不会自动放置，只提示 |
| SATISFIED | 白（一般不高亮） | 当前方块已经合法 |

只有 **PLACE / REPLACE / FORCE_REPLACE** 会真正消耗材料并被施工；CHAMBER_HINT / BLOCKED / MANUAL / SATISFIED 永远不会自动放置或替换。

</Column>

## 生存模式施工流程

普通右击控制器后，终端按顺序判断：

1. **高度校验** — 任何缺料/替换位置越界（低于世界底部，或高于 `min(世界上限, 320)`）直接拒绝，并清空当前 AE 合成会话。
2. **材料是否充足**（背包 + 已绑定的 AE 网络模拟检查）：
   - 充足且计划里**没有**替换/强拆条目 → 立即施工。
   - 充足但计划里**有** REPLACE/FORCE_REPLACE 条目 → 先"武装"待确认状态，提示"替换计划已准备；潜行右击确认施工"，需要再潜行右击同一控制器才真正执行（防止误替换/误拆）。
   - 不足且**未开 AE 模式** → 提示材料不足，建议开启 AE 模式。
   - 不足且已开 AE 模式，但绑定的 AE 节点离线/无效 → 提示绑定无效。
   - 不足且 AE 绑定有效 → 进入 AE 合成状态机（见下）。

### AE 合成状态机

材料不足且 AE 模式生效时，需要**反复右击同一控制器**推进流程；结构或开关设置在流程中途发生变化会导致会话失效需要重新开始：

| 阶段 | 玩家操作 | 系统行为 |
|---|---|---|
| 启动 | 右击控制器 | 计算缺口，对每项发起 AE 合成方案计算（不可合成的项直接报告） |
| 计算中 | 右击控制器 | 提示"仍在计算"；超过 20 秒会超时并终止会话 |
| 方案就绪 | 右击控制器 | 提交合成任务下单；部分失败也会继续推进 |
| 已下单 | 右击控制器 | 检查材料是否到齐；不足会提示"尚未全部到齐"，可再次尝试失败任务的合成方案 |
| 材料齐全 | **潜行**右击同一控制器 | 确认施工，正式建造 |

</Column>

## 设置界面（右击空气打开）

| 开关/选项 | 作用 |
|---|---|
| 等级方块（配合下方选择器） | 选择一个"等级方块家族"（如各档位仓室/机壳）+ 具体等级，供替换功能使用 |
| 重复层数（0~648） | 结构里"可重复层"的层数（GTCEu 多方块的可变层结构，如塔式反应器的可变层段）；固定层不受影响，可变层统一取这个值并夹在该层自身的合法范围内 |
| 镜像模式 | 按结构的镜像变体扫描/施工 |
| 功能部件替换 | 开启后才会启用"等级方块家族"替换：结构里同家族但等级不对的方块会被判定为 REPLACE |
| 绝对替换模式 | 开启后，结构位置上不合法的挡路方块会被强制拆除重放（BLOCKED → FORCE_REPLACE），不开则只报告不处理 |
| AE 模式 | 材料不足时是否允许使用绑定的 AE 网络库存/合成链下单补齐 |
| 无仓室模式 | 关闭（默认）：仓室位置只高亮提示，终端不会自动放置；开启：仓室位置改用普通候选方块自动填充（先起壳子，仓室自己另外插） |
| 拆解模式 | 开启后普通右击控制器会回收整座结构，而不是施工 |
| 模块检查 | 开启后左击扫描不再输出施工计划，改为高亮结构里所有"机器模块"可插槽位置，例如亚空间子模块(卫星工厂)的主机位置 |

### 等级方块替换的生效范围

只影响"候选列表里本来就包含选中家族方块"的结构位置：这些位置的目标方块统一变成选中的等级，已放置的同家族旧等级方块会被替换（旧方块优先退回背包，其次进 AE）。不含该家族的位置完全不受影响。

</Column>

## AE 网络绑定

潜行右击任意方块尝试绑定：目标必须是 ME 网络里**可操作的节点**（接口、样板供应器、控制器、ME 总线、仓室等常见 AE 方块都算），且该节点在线、所在电网有效。绑定信息（维度 + 坐标）保存在终端物品自身的 NBT 里，重新绑定、关闭 AE 模式或创造模式施工都会清空当前 AE 合成会话。

</Column>

## 常见问题

### Q: 施工按钮好像没反应？
**A:** 生存模式下"替换类"施工和"AE 材料齐全后的最终建造"都需要**潜行**右击同一控制器二次确认，普通右击不会执行。

### Q: 为什么一直卡在"结构或绑定已变化"？
**A:** AE 合成会话记录了扫描时的结构指纹和绑定坐标，中途改动结构、切换开关或重新绑定 AE 节点都会让旧会话失效，需要重新开始扫描流程。

### Q: 仓室位置为什么不会自动放置？
**A:** 默认"无仓室模式"关闭时，终端只高亮提示仓室类型（输入/输出/电源/维护/并行/消声/数据/其他），需要玩家自己判断插入哪种仓室；开启无仓室模式会先用普通方块占位，仓室仍需另外手动放。

### Q: 越界的结构为什么建不了？
**A:** 目标位置低于世界最低高度，或高于 `min(世界最大高度, 320)`（GTCEu 多方块硬性上限）时，施工会被整体拒绝。
