# 通用 GT 配方 RTUI

通用模板位于 `assets/gt_shanhai/ui/recipe_type/adaptive.rtui`。复制到资源包的 `assets/<配方类型命名空间>/ui/recipe_type/<配方类型路径>.rtui`，并把 NBT 的 `recipe_type` 改为实际配方类型 ID。重新加载资源后，可在 JEI 查看该配方类型。

模板根节点内的 `adaptive_inputs` 和 `adaptive_outputs` 分别定义投入与产出的可视区域。移动或调整这两个区域即可重新布局。每格宽高为 18，右侧预留 4 像素滚动条。区域至少宽 22、高 58，才能同时显示一排物品和一排流体。普通与逐刻物品、流体按实际条目数排列，两类条目各自滚动。空区不生成槽，超出可视高度的条目可用滚轮或拖动滚动条查看，也可通过 JEI 搜索。需要研究的配方类型保留研究槽。

摘星者的 `stellar_deconstruction.rtui` 使用单独的区域布局，并由 `StarLifterTerminalSky` 绘制与摘星工程和摘星者终端相同的星空。JEI 的功耗、时长、概率与是否消耗等提示由 GT 提供。

点击 JEI 配方右侧的全屏图标，可按窗口宽度重新排列投入和产出。多出的行仍可滚动查看。按 `Esc` 或点「完成」返回原配方。槽位数字会缩写较大的物品数量，悬停可查看精确数值。滚动范围外的条目仍可通过 JEI 搜索，在可视区域内才响应悬停和配方查询。
