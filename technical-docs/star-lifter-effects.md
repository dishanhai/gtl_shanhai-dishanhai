# 摘星者运行特效与验收

## 演出与预算

星面、日冕与特效都使用游戏刻和渲染插值。环体仍按已有的四个有符号周期转动。每个安装项沿用整体包围盒、分环剔除和恒星剔除，固定主控舱的光带另按舱体范围剔除。世界和终端共用 GLSL 程序、VBO 和几何坐标。星面使用程序化纹理，既有 Minecraft 方块图集仍提供结构材质。

| 层 | 触发与演进 | 近景提交上限 |
|---|---|---:|
| 恒星本体 | 可见时持续绘制白蓝星面、差动翻滚、慢亮斑与异向呼吸日冕。日珥随时间卷动，高负载时抬高。星表热点随采集面转动。累计采集量增加时，星面向蓝紫收缩。 | 6,144 星面顶点、4 日冕顶点和 1,536 日珥顶点 |
| 恒星物质采集 | 启动时采集口先锁定，随后星表扰动和三条金白主束形成。高负载加入三条交错主束。近景同时提交三条更细的丝束与采集口锁定环。 | 2,328 顶点 |
| 环体运行 | 四环的输运光带贴现有导槽高度运行。环号决定启动延迟及脉冲相位，外环和内侧采集环的亮度高于两个中间环。 | 936 顶点 |
| 磁场与相位约束 | 蓝青束约束星表与采集环，幽紫弧连接相邻功能轨道。高负载提高约束亮度，等待时留下断续脉冲。约束线按当前环姿态更新。 | 576 顶点 |
| 巨构空间环境 | 近景最多八枚程序化碎屑沿活跃采集区漂移。微扰局限于星冕密度与星表接触带，深度测试及距离雾控制可见范围。 | 64 顶点，空间微扰共用日冕绘制 |
| 状态反馈与固定舱 | 主控与汇流路径先建立方向性脉冲。归墟端点成立时，独立幽紫回路沿舱面共鸣。既有扣箍仍按磁体经过窗口的时刻点亮。 | 576 常驻顶点，外加既有扣箍的少量临时顶点 |

近、中、远三档光带分别提交最多 **6,016、3,032、1,376** 个参数顶点，各自使用一份跨实例共享的静态 VBO，每个装置每帧最多提交一次光带绘制。运行时只更新着色器参数。中档移除细丝和碎屑，远档保留主要抽取、约束、节点与轨道输运。距离阈值为基准半径的 1.9 倍与 3.6 倍。超过四个可见装置时，近档上限降至 1.36 倍半径。终端固定使用中档，单环视图按选中环遮罩输运，恒星观测保留接触热点与星体演出。终端「世界近景增强特效」开关可将世界近景降为中档。

## 状态来源

| 状态 | 来源与表现 |
|---|---|
| 待机 | 无工作配方或生产暂停。保留星体、低亮导槽和少量锁口灯。 |
| 启动 | 进入真实配方工作后的 64 游戏刻。固定舱、四环、采集口和抽取束分时建立。已经工作时改变负载，延续原来的启动时刻。 |
| 正常 | 配方持续工作。三条主束传送金白脉冲，相位线低亮，四环分相输运。 |
| 高负载 | 实际配方并行数大于一，或配方输入 EU/t 达到 UEV 档额定电压。主束加粗，加开交错节点，表面热点和日珥提高，输运及锁定节点增加快速脉冲。 |
| 归墟联动 | 保存的归墟模块、所属主机与摘星者均实际成型且远端区块已加载。联动叠加于当前状态，跨维度时在本地主控端呈现星渊共鸣回路。 |
| 故障 | 储量耗尽或配方进入等待时，约束与单条局部抽取束间歇闪动。结构失效后世界按已有生命周期撤去动态装置，终端诊断预览显示故障状态。 |

服务端每五个游戏刻采样已登记主机，只在模式、联动或储量等级变化时更新该维度快照。世界和终端同源取值。演出状态从现有主机数据重算，历史存档沿用原来的结构数据。网络协议已升至 27，联机需使用同版客户端与服务端。

### 采集量与星面形态

满储量沿用白蓝色和约 29.6 格星面半径。消耗一半时半径约 26.6 格，耗尽时约 23.7 格，星面和星冕逐渐偏向较暗的蓝紫色。半径从 100% 连续缩到 80%。现有采集储量按 1/1024 归一化，同步后在 30 个游戏刻内插值。连续采集与补给会从当前可见状态接续，重新载入存档时直接读取当时的形态。

星冕切圆、日珥、场线和抽取束端点、备用恒星贴图、恒星碰撞体以及终端观测半径共用该比例。环体与固定舱继续使用安装时的尺寸和碰撞数据。

## 验收入口

使用 Forge 1.20.1 独立存档副本。成型摘星者在 (602, 204, 514)，真实归墟主机及摘星模块位于下界。夹具给成型摘星者提交可控的 GT 工作批次，用两档并行数验证模式，并通过已有的跨维度绑定入口连接和解绑。储量耗尽场景通过隔离存档的储量触发 WAITING。星面变化用同机位记录满储量、剩余一半、耗尽和实际扣除材料后的再激活。多实例场景在真实主机旁加入同渲染路径的客户端夹具。终端由原生右键打开。

帧间隔来自相邻 Forge 渲染开始事件。世界与光带 GPU 时间来自 OpenGL 时间戳查询。样本受整合包、区块调度和固定镜头影响，应用于本次录像和同机对照。

## 对照结果

在 Java 21、Forge 47.4.16、RTX 4060 Laptop GPU、2560 × 1601 画面、20 区块视距下采样。垂直同步与光影关闭。对照使用已有整机终端特效的旧包 final-integrated.jar。每个计时观测窗为 120 游戏刻。两轮顺序运行，使用同一存档源和机位。满储量、半储量、耗尽和真实扣料补给后的服务端确认值依次为 1.0、0.5、0.0、1.0。382 项定向测试通过。

## 待扩展项

当前热扰动在星冕和接触点内部求值。对背景场景做局部折射、额外剖切平面、高级 Bloom 和专属观测运镜均列为后续项目。独立服务器上的多座真实生产主机、光影开启路径、实际高刷新率输出和长期显存趋势仍需专门测量。
