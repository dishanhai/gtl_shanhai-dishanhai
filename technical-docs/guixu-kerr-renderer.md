# 归墟 Kerr 黑洞渲染

归墟视界枢核和客户端黑洞预览共用两段 OpenGL 渲染。第一段按观察者位置和姿态追踪零测地线，将 HDR 辐射、透射率、逃逸方向和捕获标志写入浮点纹理。第二段进行背景采样、深度遮挡、两帧重投影、曝光、色调映射和辐射泛光。

## 入口与参数

- 成型归墟使用主机的渲染半径、自旋和吸积热度。客户端预览使用 `/shanhai bh center <x> <y> <z>`。
- `/shanhai bh kerr panel` 打开实时调试面板。`/shanhai bh kerr` 输出视界、ISCO 和 GPU/CPU 读数。`/shanhai bh kerr spin -0.95` 覆盖自旋，`spin auto` 恢复跟随主机或配置。
- 客户端 Forge 配置的 `[kerr]` 节可设持久默认值。`KerrControls` 供客户端调用，覆盖不写回配置。质量档为 Ultra、High、Medium、Low 和 Adaptive，均运行同一个积分器。
- 质量倍率、自旋、自旋轴、观察距离和倾角使用几何模型。距离以 `GM/c²` 为单位，0 跟随玩家。倾角 −1 跟随玩家与轴之间的角度。相对吸积率、温度、盘厚和辐射系数属于盘模型参数。曝光、泛光、背景、模拟时间倍率和世界背景位移强度属于显示控制。
- 常规数值参数、背景和质量设置平滑过渡。反向盘轨道切换先淡出辐射与吸收，切换圆轨道方向后恢复。
- 主机外层星场覆盖距环心 76～168 格的空间。独立星空背景使用带尘带的银河和按出射光束角宽过滤的星点。群星终焉把吞噬、回弹和释放阶段的亮度送入盘面热度，内盘温度和差速等离子体亮纹随供料变化。游戏事件控制的加热、银河外观和显示曝光属于视觉建模。
- Adaptive 和 Low 在近场或画面覆盖较大时，按像素预算缓存盘面辐射与泛光。世界颜色和深度仍以显示分辨率采样。阴影附近用 Kerr 径向势计算到临界曲线的有符号距离，再按显示像素的宽度平滑过渡。轮廓处的暖色细弧和内侧紫色余辉属于显示特效，沿自旋轴绕行，亮度跟随吸积热度。关闭吸积盘后，流光也随之关闭。GPU 反馈计时涵盖光线积分、补采样与合成。

## 数值模型

积分采用出射 Cartesian Kerr–Schild 坐标、度规符号 `(-+++)` 及 `G=c=M=1`。反向光线在观察者的局部 Eulerian 正交标架发射。逆度规写成 `η^μν − 2H l^μ l^ν`，积分空间位置、空间正则动量和坐标时间，利用平稳性固定 `p_t`。Bogacki–Shampine 3(2) 嵌入式积分按位置和动量误差拒绝步长，另以径向速度限制跨视界的小步。达捕获阈值时停止，极端自旋使用专用阈值。径向视界间距和圆轨道固有时表达式使用减轻浮点消减的形式。拖曳包含在度规中。Java API 的 ZAMO 拖曳、lapse、外/内视界、能层、视界面积、角速度、光子区域和 ISCO 可单独验证。坐标和积分背景参考 [GRay2](https://arxiv.org/abs/1706.07062) 与 [Bardeen、Press、Teukolsky](https://doi.org/10.1086/151796)。

逃逸方向来自有限半径处的测地线。每条路径可沿线多次穿过发射体，按观察者方向累积每段辐射和光深，捕获只关闭光线远端的背景。薄盘使用 ISCO 零力矩的近似温度律和高斯垂直密度，圆轨道速度与局部频移由 Kerr 几何计算。采用三个显示波段采样普朗克谱。频移通过发射体四速度与光子动量的内积计算，包含引力红移、相对论多普勒和发射率变换。盘面图样以局部轨道角速度差速平移，并使用有限相干时长模拟湍流演化。完整相对论盘通量的参考为 [Page–Thorne](https://articles.adsabs.harvard.edu/pdf/1974ApJ...191..499P)。

## 验证

用 JDK 21 在项目根目录运行以下命令。

```powershell
.\gradle-install\gradle-8.8\bin\gradle.bat --offline test --tests '*renderer.blackhole.*' --tests '*renderer.hostfx.*' build
.\gradle-install\gradle-8.8\bin\gradle.bat --offline kerrGpuProbe -PkerrStabilityFrames=125000
```

GPU 探针直接加载生产 GLSL，在 `build/reports/kerr-gl` 输出三种观察倾角、史瓦西极限及正负极端自旋的 PNG。测试使用有限距离、Eulerian 运动修正后的解析史瓦西临界角，检查自旋镜像、误差收敛、零测地线约束、轴向动量和 Carter 常数漂移。两张 Golden Image 使用降采样后的平均 RGB 误差和离群像素比例容许少量驱动差异。侧视图的盘背高阶成像以及趋近侧增亮与 [NASA Schwarzschild 可视化](https://svs.gsfc.nasa.gov/13326) 做定性对照。该参考的观测条件和盘模型与归墟不同。

近场回归使用轴向距离 14、4.7、3.7 个引力半径的机位，并包含转身朝外观测。参照图使用两倍宽高的光线网格和更严格的积分容差。测试比较亮边颜色、抖动相位和盘面暗部的相邻像素差。太阳回归实际调用 Minecraft 1.20.1 的 BlendMode，在蓝天下绘制原版太阳资源并回读中心和边角颜色。

盘内辐射在积分步的 Hermite 曲线上分段求积，近场使用更严格的误差控制。对于 ISCO 内向内传播的光线，若 Carter 径向势在当前位置至外视界的区间上具有全正的 Bernstein 系数，可提前确认捕获。GPU 探针将其与逐步抵达视界的积分比较。对像素覆盖率使用的解析分类另行核对内向、外向和不同自旋的数值光线。

本轮通过 189 项定向测试和 1,200 帧连续离屏渲染。在 800×560 输出、40% 基础采样的测试中，4.7 机位的亮边蓝通道平均绝对误差依次为 25.53（仅基础采样）、12.19（自适应辐射缓存）、4.55（原生像素补采样），单位为 8 位灰阶。盘面暗弧测试区的相邻红通道最大差为 2。858,848 条已收敛光线中，径向势与逐步分类有 4 条差异。Golden Image 由两倍宽高、容差 0.000009 的高采样输出缩小生成。

RTX 4060 Laptop GPU、2560×1600 输出、独立星空背景下，轴向距离 26、14、4.7 个引力半径的积分与合成分别耗时 11.85、18.32、37.82 毫秒，基础采样比例分别为 40%、40%、45%。在 4.7 机位使用 20% 基础采样和双子样本时为 10.02 毫秒。该计时不包含 Minecraft 世界与其他模组开销。低预算下未分辨的细子环依然受辐射场分辨率限制。

近景轮廓优化的独立对照使用 RTX 4060 Laptop GPU、2560×1600 输出和相同光线网格。三轮各取 18 帧的 GPU 平均耗时，再取三轮中位数。4.7 M 机位默认 Adaptive 从 6.79 降至 5.84 毫秒，反馈降档后从 4.33 降至 3.64 毫秒。14 M 机位默认 Adaptive 从 6.75 降至 6.09 毫秒。在 800×560 输出、13% 基础采样下，史瓦西阴影的 1,812 个边界像素与每像素 256 个几何子样本的参考覆盖率平均相差 0.9 个百分点。计时仅包含黑洞渲染。

## 近似和验收边界

- 模型采用固定 Kerr 背景加解析辐射盘。密度、温度尺度、灰吸收和假色属于显示建模，盘自引力、磁流体演化及逐频散射未求解。游戏方块对应相对质量与长度比例。物理单位的质量和角动量换算通过 Java API 提供。
- 世界背景来自 Minecraft 当前帧的颜色与深度。用洞心平面及场景深度估计有限距离物体的屏幕位移，按逃逸方向、缓存边距和显示强度限制取样范围。采样位置须能按其深度投回目标像素，四个颜色插值点均需在洞后。缺失的视角保留原场景。盘面与独立星空使用完整测地线结果。完整三维世界沿测地线再渲染和 Oculus 世界深度仍属限制。
- 开启视角摇晃时，从完整逆投影恢复光心和射线。普通世界深度路径把洞前原版方块选框的线顶点留到透镜之后提交，沿用资源包的线着色器。自行绘制高亮的第三方模组及开启光影包时的选框需单独验收。
- 近视界算法按步数上限终止。未决光线保留已积分的前景辐射并使用本视线背景。子像素高阶子环仍受分辨率和步数限制。视界外观察者使用 Eulerian 标架，玩家的移动速度不叠加为额外的洛伦兹变换。内视界供数学计算，洞内的旧调试效果独立且默认关闭。
- 时域历史含上一帧测地线方向和辐射，支持近似固定位置下的相机旋转重投影。采样分辨率有上限，快速平移、参数大幅变化或超出缓存时降低或舍弃历史。持久多视角光线路径缓存尚未实现。
- 隔离开发客户端到达 Forge 模组加载，GTL Additions 要求 Oculus。现有发行版 Oculus 在开发映射已有 Mixin 加载错误。上述 PNG 与计时来自实际 GPU 离屏渲染。游戏内面板、成型主机截图、整合包性能和 Oculus 组合测试待验收。
