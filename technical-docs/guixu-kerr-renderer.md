# 归墟 Kerr 黑洞渲染

归墟视界枢核与客户端预览共用 Kerr 渲染器。默认 Adaptive 和 Low 至 Scientific 各档都从玩家相机反向积分零测地线。光线可以多次穿过吸积盘，浮点纹理记录累计辐射、透射率、逃逸方向和捕获状态。相机转向或拉远后仍使用同一光学模型。兼容档使用独立的屏幕空间近似。

## 入口与参数

- 成型归墟使用主机的渲染半径、自旋和吸积热度。客户端预览使用 `/shanhai bh center <x> <y> <z>`。
- `/shanhai bh kerr panel` 打开实时调试面板。`/shanhai bh kerr` 输出视界、ISCO 和 GPU/CPU 读数。`/shanhai bh kerr spin -0.95` 覆盖自旋，`spin auto` 恢复跟随主机或配置。
- 客户端 Forge 配置的 `[kerr]` 节可设持久默认值。`KerrControls` 提供临时覆盖。新配置的自旋为 0.95，盘外半径为 40 rg，盘厚 H/r 为 0.06。已有配置和主机自旋优先。用 `/shanhai bh kerr outer_radius 24` 可实时调整外缘，范围为 12～64 rg。盘内缘跟随当前轨道方向的 ISCO。
- 质量倍率、自旋、自旋轴、观察距离和倾角使用几何模型。距离以 `GM/c²` 为单位，0 跟随玩家。倾角 −1 跟随玩家与轴之间的角度。相对吸积率、温度、盘厚和辐射系数属于盘模型参数。曝光、泛光、背景、模拟时间倍率和世界背景位移强度属于显示控制。
- 常规数值参数、背景和质量设置平滑过渡。反向盘轨道切换先淡出辐射与吸收，切换圆轨道方向后恢复。
- 主机外层星场覆盖距环心 76～240 格，保留 168 格以内的较近星点。局部星尘与黑色背景最大半径为 44 格，克尔模式在物理视界附近淡出背景，旧版模式沿用洞内透镜的进入距离。独立星空背景使用带尘带的银河和按出射光束角宽过滤的星点。群星终焉把吞噬、回弹和释放阶段的亮度送入盘面热度，内盘温度和差速等离子体亮纹随供料变化。游戏事件控制的加热、银河外观和显示曝光属于视觉建模。
- 调试面板标注兼容档为屏幕空间近似。该档用投影环带、背侧弧和远景微型高光构图，状态栏显示 `L0 analytic`。测地线路径显示 `GRRT trace=宽x高`，捕获光线仍保留捕获前已穿过的前景辐射。世界背景使用游戏当前帧的颜色和深度。
- Adaptive 和 Low 按像素预算缓存盘面辐射，在适用机位沿临界曲线额外积分窄带光线。近于 16 M 的广角机位使用有界的像素传输缓存。测地线各档从实际 HDR 辐射生成多尺度泛光，并对符合历史有效条件的帧进行重投影。GPU 计时涵盖窗口采样和实际合成。
- 高分辨率下，将额外的盘面采样集中在阴影和相邻亮弧，并在视界附近收紧采样预算。临界曲线附近按像素内的光束面积重建辐射，复用沿曲线采样的细弧。世界透镜根据背景源坐标的屏幕导数确定过滤方向和范围，每个采样点仍受场景深度约束。光束覆盖和各向异性过滤参考 [Bruneton 的实时黑洞着色器](https://ebruneton.github.io/black_hole_shader/black_hole/functions.glsl.html)、[DNGR 论文](https://arxiv.org/html/1502.03808#S2.SS3) 和 [pbrt 纹理过滤](https://www.pbr-book.org/4ed/Textures_and_Materials/Image_Texture#sec:ewa)。

## 数值模型

积分采用出射 Cartesian Kerr–Schild 坐标、度规符号 `(-+++)` 及 `G=c=M=1`。反向光线在观察者的局部 Eulerian 正交标架发射。逆度规写成 `η^μν − 2H l^μ l^ν`，积分空间位置、空间正则动量和坐标时间，利用平稳性固定 `p_t`。Bogacki–Shampine 3(2) 嵌入式积分按位置和动量误差拒绝步长，另以径向速度限制跨视界的小步。达捕获阈值时停止，极端自旋使用专用阈值。径向视界间距和圆轨道固有时表达式使用减轻浮点消减的形式。拖曳包含在度规中。Java API 的 ZAMO 拖曳、lapse、外/内视界、能层、视界面积、角速度、光子区域和 ISCO 可单独验证。坐标和积分背景参考 [GRay2](https://arxiv.org/abs/1706.07062) 与 [Bardeen、Press、Teukolsky](https://doi.org/10.1086/151796)。

稳态赤道薄盘采用 Page–Thorne 的 ISCO 零力矩边界。取几何单位，通量正比于 `−Ω′ (uᵗ)²/r × ∫(dL/uᵗ)`。CPU 在自旋、轨道方向或外半径改变时重算径向表，每个区间用两点高斯求积。128 个节点在 ISCO 附近加密，着色器插值通量平方根。有效温度取通量的四次方根，绝对温度标定、主机加热和供料亮纹由游戏参数控制。[Page 与 Thorne 原文](https://thesis.caltech.edu/7179/1/Page_dn_1976.pdf)

盘大气采用高斯垂直密度。沿测地线分段累积光深，在三个可见光波段采样频移后的普朗克谱。局部观测频移由光子动量与圆轨道四速度决定。亮纹在随物质运动的坐标中求值，方位方向首尾相接，开普勒差速、径向平流和光传播时延共同决定纹理相位。细丝按求积步长过滤。盘内波动属于程序化湍流近似。

## 验证

### 透镜采样与视锥剔除

世界透镜按当前样本的深度平面估算源像素足迹。相邻像素因前景而拒绝偏折取样时，保留未偏折的颜色，已接受的相邻样本按自身足迹过滤。压缩方向使用各向异性的三角权重。2560×1600 离屏探针中，两轴条纹的残余振幅由 54、36 降到 29、30，遮挡边界附近已接受样本的最大红通道误差由 70 降到 0，单位均为 8 位色阶。

近景吸积盘使用限幅三次重建，并在高分辨率近景增加前景盘的采样密度。固定 160×96 基础网格的近景探针中，开启泛光时暗部平均 RGB 误差由 0.449 降到 0.350，关闭泛光时盘缘误差为 2.577，改动前为 2.563。视锥剔除按被近裁面截取的发光包围球投影，临界曲线辅助采样在其覆盖范围完全离屏时跳过。剔除回归覆盖洞心离屏、体积跨越相机平面及整体退到镜头后方。

Forge 47.4.16 隔离存档的成型归墟以 2560×1601 运行。距洞心 90 格时绘制矩形为 914×913，原地转向后停止提交黑洞绘制，回到截图坐标后恢复。近景世界透镜路径的黑洞 GPU 读数中位数为 24.91 ms，采集了 20 条逐秒读数。该次测试使用可读的世界深度，Oculus 光影包未启用。

### Page–Thorne 薄盘与默认测地线路径

黑洞与归墟主机渲染的 212 项定向测试全部通过。RTX 4060 Laptop GPU 使用生产着色器连续渲染 1,200 帧。史瓦西捕获半径理论值为 61.06 像素，测得 61 像素。自旋 0.65、倾角 65° 和 86° 的图像相对高采样参考图的平均 RGB 绝对误差分别为 0.262/255 和 0.242/255。自旋 ±1 的两个视角各有 13/232,704 条光线达到步数上限。

使用 Forge 47.4.16 的隔离整合包进入单人存档，通过游戏命令实测了世界背景、独立星空、零自旋、盘外缘调整、兼容档往返和参数面板。在 1024×640、距离 36 M、自旋 0.95、倾角 80° 的世界背景预览中，Adaptive 使用 136×88 光线网格，黑洞渲染 GPU 读数为 5.09 ms。切到兼容档后为 0.09 ms。原存档机位、成型主机与启用光影包的观测仍待复核。

### 复现入口与历次对照

按客户端日志重建 2560×1600、160×96 基础网格的近景。盘缘高反差像素相对双倍采样参考图的平均 RGB 误差从 15.74 降到 4.77，开启泛光后的暗部误差从 2.46 降到 0.74，单位均为 8 位灰阶。双向压缩的世界背景条纹在两个方向的残留振幅从 255 降为 54 和 36。RTX 4060 Laptop GPU 上的局部细节积分约用 3.1 ms。原存档的隔离副本在雨天近景通过两条路径的实测，2560×1601 下仅物体路径的 GPU 中位数为 6.73 ms，开启世界透镜时为 20.57 ms。

针对高自旋时阴影下沿、背侧亮弧和星点断续的问题，Adaptive 与 Low 在投影洞心附近额外积分一块最多 224×224 的屏幕区域。它同时记录辐射、透射率和逃逸方向，补到前景盘横穿阴影的区域。小目标按显示像素对齐，外围平滑衔接原采样网格。临界曲线上的亚像素窄弧继续使用沿曲线的高精度采样。

固定 1024×640、自旋 0.95、倾角 80°、距离 36 M、基础光线网格 136×88，与双倍宽高的参考图比较。4,748 个高反差边缘像素的 RGB 平均绝对误差从 11.32 降至 2.67（8 位灰阶）。关闭吸积盘单测星空偏折，在洞心周围 30,717 个像素上，误差从 0.809 降至 0.171。局部泛光从同一组精细辐射样本提取，避免低分辨率亮斑在黑影里留下方格。开启 0.18 泛光时，6,008 个暗部像素的误差从 8.572 降至 0.902。

隔离整合包复测使用同一存档、镜头、自旋、固定模拟时钟和独立星空。RTX 4060 Laptop 在 136×88 基础网格下，黑洞 GPU 耗时的逐秒读数中位数由 2.62 ms（13 次）变为 3.30 ms（11 次）。前后帧的相同区域以最近邻放大两倍进行对照。

用 JDK 21 在项目根目录运行以下命令。

```powershell
.\gradle-install\gradle-8.8\bin\gradle.bat --offline test --tests '*renderer.blackhole.*' --tests '*renderer.hostfx.*' build
.\gradle-install\gradle-8.8\bin\gradle.bat --offline kerrGpuProbe -PkerrWidth=1024 -PkerrHeight=640 '--args=build/reports/kerr-edge/after disk-edge'
.\gradle-install\gradle-8.8\bin\gradle.bat --offline kerrGpuProbe -PkerrStabilityFrames=125000
.\gradle-install\gradle-8.8\bin\gradle.bat --offline kerrGpuProbe -PkerrWidth=2560 -PkerrHeight=1600 '--args=build/reports/kerr-exterior-aligned exterior'
```

解析路径在 RTX 4060 Laptop GPU 上按 2560×1600 离屏测量。11.5 M、29.3 M 和 180 M 机位分别用 3.08、2.02 和 1.37 毫秒。近景中心轴上的裸阴影过渡占 1 个原生像素。探针把辐射和逃逸纹理替换为明显的假值，输出保持逐像素一致。输出图覆盖白天、深空 65°、侧视 86°和亚像素特效。计时只含离屏合成。

GPU 探针直接加载生产 GLSL，在 `build/reports/kerr-gl` 输出三种观察倾角、史瓦西极限及正负极端自旋的 PNG。测试使用有限距离、Eulerian 运动修正后的解析史瓦西临界角，检查自旋镜像、误差收敛、零测地线约束、轴向动量和 Carter 常数漂移。两张 Golden Image 使用降采样后的平均 RGB 误差和离群像素比例容许少量驱动差异。侧视图的盘背高阶成像以及趋近侧增亮与 [NASA Schwarzschild 可视化](https://svs.gsfc.nasa.gov/13326) 做定性对照。该参考的观测条件和盘模型与归墟不同。

近场回归使用轴向距离 14、4.7、3.7 个引力半径的机位，并包含转身朝外观测。参照图使用两倍宽高的光线网格和更严格的积分容差。测试比较亮边颜色、抖动相位和盘面暗部的相邻像素差。太阳回归实际调用 Minecraft 1.20.1 的 BlendMode，在蓝天下绘制原版太阳资源并回读中心和边角颜色。

盘内辐射在积分步的 Hermite 曲线上分段求积，近场使用更严格的误差控制。对于 ISCO 内向内传播的光线，若 Carter 径向势在当前位置至外视界的区间上具有全正的 Bernstein 系数，可提前确认捕获。GPU 探针将其与逐步抵达视界的积分比较。对像素覆盖率使用的解析分类另行核对内向、外向和不同自旋的数值光线。

本轮通过 189 项定向测试和 1,200 帧连续离屏渲染。在 800×560 输出、40% 基础采样的测试中，4.7 机位的亮边蓝通道平均绝对误差依次为 25.53（仅基础采样）、12.19（自适应辐射缓存）、4.55（原生像素补采样），单位为 8 位灰阶。盘面暗弧测试区的相邻红通道最大差为 2。858,848 条已收敛光线中，径向势与逐步分类有 4 条差异。Golden Image 由两倍宽高、容差 0.000009 的高采样输出缩小生成。

RTX 4060 Laptop GPU、2560×1600 输出、独立星空背景下，轴向距离 26、14、4.7 个引力半径的积分与合成分别耗时 11.85、18.32、37.82 毫秒，基础采样比例分别为 40%、40%、45%。在 4.7 机位使用 20% 基础采样和双子样本时为 10.02 毫秒。该计时不包含 Minecraft 世界与其他模组开销。低预算下未分辨的细子环依然受辐射场分辨率限制。

近景轮廓优化的独立对照使用 RTX 4060 Laptop GPU、2560×1600 输出和相同光线网格。三轮各取 18 帧的 GPU 平均耗时，再取三轮中位数。4.7 M 机位默认 Adaptive 从 6.79 降至 5.84 毫秒，反馈降档后从 4.33 降至 3.64 毫秒。14 M 机位默认 Adaptive 从 6.75 降至 6.09 毫秒。在 800×560 输出、13% 基础采样下，史瓦西阴影的 1,812 个边界像素与每像素 256 个几何子样本的参考覆盖率平均相差 0.9 个百分点。计时仅包含黑洞渲染。

细弧回归在 800×560 输出、65° 倾角取临界曲线附近的 1,560 个像素。对照四倍宽高的高精度参考图，72% 原生路径的平均 RGB 误差从 6.75/255 降到 3.71/255，13% 光线网格和 22% 传输网格的缓存路径从 22.42/255 降到 5.46/255。RTX 4060 Laptop GPU 每组取 18 帧，原生路径开关前后为 5.17 和 4.85 毫秒，缓存路径为 0.66 和 1.58 毫秒，计时包含积分和合成。静止机位的逃逸方向缓存与完整积分有相同的光线分类、逃逸方向及半精度盘面数据。定向测试通过 209 项，连续离屏运行通过 1,200 帧。

本次 2560×1600 独立测量里，14 M 和 4.7 M 的默认 Adaptive 预算分别用 3.74 和 4.56 毫秒，反馈降档后分别为 2.07 和 2.44 毫秒。改动前先跑的相同预算场景分别为 3.29、3.08、1.39 和 1.56 毫秒。近景缓存的本次计时高于改动前，原生窄带的同轮开关对照见上一段。这些数据是黑洞渲染开销，整合包帧率需在游戏机位采集。

## 性能与复测

Adaptive 和 Low 在无采样抖动时可以复用完全一致的黑洞帧。相机、盘面时钟、光学参数、曝光、泛光和采样预算都匹配时，复用基础光线、细节块、泛光和像素传输缓存。当前帧仍采集实际世界颜色和深度。相机固定但吸积盘继续流动时，只复用符合条件的逃逸方向和临界曲线，盘面辐射继续积分。调试状态中的 `blackReuse` 记录整帧光学缓存命中次数。

细节块保留中心的严格积分容差，向盘外缘逐渐放宽，并跳过屏幕与泛光采样范围都用不到的光线。亮弧窄带仍用严格积分。关闭背景时，光线在离开发光区后即可停止追踪方向。吸积盘同时熄灭时，可直接从径向势求捕获分类。

可用 `gradle kerrGpuProbe -PkerrWidth=2560 -PkerrHeight=1600 --args="build/reports/kerr-perf performance"` 测量世界背景合成、基础光线及局部细节耗时。使用 `-PkerrShaderRoot=<着色器 core 目录>` 可在同一探针运行另一版 GLSL。开启泛光的两组 2560×1600 近景中，细节追踪分别由 3.56 降至 3.34 毫秒、由 3.09 降至 2.91 毫秒。关闭背景且吸积盘熄灭时，测试用基础光线阶段由 0.186 降至 0.005 毫秒。以上是阶段时间，整机帧率应在整合包机位测量。

Forge 47.4.16 隔离客户端以 1600×1000、世界透镜、12 格、冻结盘面时钟验收。黑洞稳定显示，最后一条读数记录 3,460 帧中的 3,456 次整帧缓存命中。预热后 51 条黑洞 GPU 读数的中位数为 9.17 毫秒。基线随后换了机位，同一机位的数据只覆盖预热期。画质探针覆盖 800×560 和 2560×1600 的上下亮弧、世界遮挡、星空及泛光。

## 近似和验收边界

- 模型采用固定 Kerr 背景加解析辐射盘。密度、温度尺度、灰吸收和假色属于显示建模，盘自引力、磁流体演化及逐频散射未求解。游戏方块对应相对质量与长度比例。物理单位的质量和角动量换算通过 Java API 提供。
- 世界背景来自 Minecraft 当前帧的颜色与深度。用洞心平面及场景深度估计有限距离物体的屏幕位移，按逃逸方向、缓存边距和显示强度限制取样范围。采样位置须能按其深度投回目标像素，四个颜色插值点均需在洞后。缺失的视角保留原场景。盘面与独立星空使用完整测地线结果。完整三维世界沿测地线再渲染和 Oculus 世界深度仍属限制。
- 开启视角摇晃时，从完整逆投影恢复光心和射线。普通世界深度路径把洞前原版方块选框的线顶点留到透镜之后提交，沿用资源包的线着色器。自行绘制高亮的第三方模组及开启光影包时的选框需单独验收。
- 近视界算法按步数上限终止。未决光线保留已积分的前景辐射并使用本视线背景。子像素高阶子环仍受分辨率和步数限制。视界外观察者使用 Eulerian 标架，玩家的移动速度不叠加为额外的洛伦兹变换。内视界供数学计算，洞内的旧调试效果独立且默认关闭。
- 时域历史含上一帧测地线方向和辐射，支持近似固定位置下的相机旋转重投影。像素按透射率、捕获分类和辐射差异剔除失效历史。Adaptive 和 Low 在观察射线网格、自旋、质量尺度和积分参数吻合时复用逃逸方向纹理。有像素抖动时隔帧更新光线相位。命中光线仍积分盘面辐射，抵达发光区外即结束。动态机位继续实时积分，离线多视角 LUT 尚未实现。
- 游戏内预览使用生产映射和安装了 Oculus 的整合包，测试期间关闭光影包。整机帧率仍需结合原存档和具体光影包测量。
