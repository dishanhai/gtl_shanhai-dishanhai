# 山海的神人私货

[![Minecraft](https://img.shields.io/badge/Minecraft-1.20.1-green.svg)](https://www.minecraft.net/)

给 GTL 整合包用的格雷附属模组。当前版本 **4.5.1**。作者：dishanhai/山海恒长在。

请安装发布页里的完整包。只放模组文件本身，游戏里不会有这套内容。

仓库：<https://github.com/dishanhai/gtl_shanhai-dishanhai>

---

## 安装

1. 打开 [发布页](https://github.com/dishanhai/gtl_shanhai-dishanhai/releases)，下载对应版本的完整包。
2. 按包内说明放进 GTL 整合包。
3. 进游戏后看更新公告。需要查机器和配方时，用指南书「山海的神人私货引索」。

---

## 依赖

装在 **Minecraft 1.20.1**、**Forge 47.4.16** 及以上。

必须有：

| 模组 | 版本 |
| --- | --- |
| 格雷社区版（GTCEu） | 1.4.4 及以上 |
| GTLCore | 1.2.2.9 及以上 |
| gtladditions | 3.1 及以上 |
| KubeJS | 2001.6.5-build.14 及以上 |
| GuideME | 20.1.14 及以上 |
| ae2wtlib | 15.3.3 及以上 |

gtl_extend 是可选依赖，没有版本下限。整合包里一般已经带上，也可以自己另装。装上之后，原初六源统御核心会用到它的大型虚空泵。

样板、商店和钱包还会用到这些，GTL 整合包里通常已经带上：

- 应用能源 2（AE2）
- JEI
- GTMThings（商店扣除无线电网里的电）
- FTB 任务、FTB 队伍
- Curios（钱包槽）
- ExtendedAE、ExtendedAE Plus（星律样板界面）

## 里面有什么

**终焉与原初**

终焉创始现实修改矩阵、原始终焉引擎，以及装在引擎上的原初机器：质能、薪火裂解、渊薮炼化、生物、混沌解构、物质重组与铸造、因果编织、奇点反演、世界碎片、装配、临界加工、多维聚爆、超临界物质、宇宙反应、分子裂隙与分子操纵、天琼组装、永恒熔炼、世线、量子扭曲、韶光聚合、六源统御、深空汲取、万象衍生、寰宇模拟与寰宇探源、未央重构、世线蚀刻、铸币、分歧、反熵冷凝、太虚宇宙锻炉、真空零点能。

另外还有星云虹吸、引力波天线、世线裂解、黑洞遏制、永恒格雷工坊、空间缩放、集成装配、综合组装、盒系统、代理执行、奇点数据、量子净化、天界领航、质量发生、物质定增等后期机器。

**样板与供料**

星律样板总成可以按配方自动生产，也能把一批配方收成一张通配样板。样板生成工具用来筛选配方、批量做样板。无线样板管理终端可以远程查看和调整星律。

还有可请求的库存输入、输出矩阵、自合成仓、虚拟物品供应、超级磁盘阵列和终极终端，用来接 AE 网络。

**商店**

背包或钱包槽里有山海钱包时，可以打开山海商店。商品可以是物品或流体，也可以设成免费。结算可以用星火，也可以用无线电网里的电。

货币中心负责换币和转星火。银会中心负责会员折扣，银行可以存贷。阶段没解锁时，可以让 AE 帮忙补齐前置。

大量无限盘与阶段资源、抽奖、货币等系统

**配方**

大量简化配方与自定义配方

带配方修改器时，可以在配方页面里直接改这条配方。创始演算器、万象原核、寰宇模拟单元、寰宇电路重组单元用在终局配方里。

更细的更新写在游戏内公告里。

## English

**Shanhai** is a GregTech addon for the GTL modpack on Minecraft 1.20.1. The current release is **4.5.1**.

Download the complete package from [Releases](https://github.com/dishanhai/gtl_shanhai-dishanhai/releases) and follow the instructions inside. The mod file alone does not add this content.

It needs Forge 47.4.16 or newer, GTCEu 1.4.4+, GTLCore 1.2.2.9+, gtladditions 3.1+, KubeJS 2001.6.5-build.14+, GuideME 20.1.14+, and ae2wtlib 15.3.3+. gtl_extend is optional. AE2, JEI, GTMThings, FTB Quests, FTB Teams, Curios, and ExtendedAE are used by the pattern, shop, and wallet features and normally come with the GTL pack.

It adds late-game multiblocks, AE pattern crafting, a player shop with Spark currency, and an in-game guidebook. Patch notes are shown when you join the game.
