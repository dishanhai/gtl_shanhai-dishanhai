# gt_shanhai 4.4.0

发布日期：`2026 年 10 月 TBD 日`
此更新贡献者：**dishanhai**——`核心代码贡献者`

## 配置界面

- 模组列表里的`配置`补上原先只能手改 `gt_shanhai-common.toml` 的项目。
- `配方类型样板总成`增加`卡死告警延迟`和`虚拟供料单次并行上限`。
- 新增分类：`高级样板包装箱`、`样板总成工具箱`、`商店银行`、`缓存与诊断`、`开发`。
- `商店`增加`奖励抽取次数上限`和`出售回收比例`。
- `机器行为`增加`AE 库存强制重扫间隔`。只在增量缓存开启时生效。
- `商店银行`可以改存款基点、贷款基点、最大欠款和贷款期限。
- `缓存与诊断`可以开关运行期配方缓存统计，以及 KJS 配方库磁盘缓存。后者默认关闭，改完要重启。
- `开发`可以开关`开发模式`。关闭时配方修改器仍导出到游戏目录 `kubejs/data/Exported_Recipe/`。打开后写到这台开发机的模组源码 recipes 目录。其他机器没有这个目录，导出会失败。
- 星律样板总成点`恢复默认`时，每行槽位、每页行数、最大页数都回到 `10`。已放置的总成在下次区块加载时采用新配置。调小会裁掉高位槽，里面的样板掉在机器位置，内部缓冲料留不住。

## 原初渊薮精炼塔

- 增加配方类型`太素衍化`。
- 物品说明由`七源归一`改为`八源归一`。类型列表末尾加上太素衍化。

## 配方修改器

- JEI 配方页增加`编辑此配方`。背包里有配方修改器、并且权限等级达到 2 时才会出现。缺工具或缺权限时，聊天栏会说明原因。
- 修改器快照里还没有这条配方时，会先从当前配方表抓取再打开。
- 输入格新放入的编程电路，概率仍是默认时改为`不消耗`。悬停会写出电路号等细节。
- 右键改为取消选取。中键打开选取器。
- 物品格、流体格可以在精确 ID 和标签匹配之间切换。悬停、样板编码和 JS 导出都会保留这个选择。
- 可以编辑配方温度。线圈选择器按线圈温度写入配方温度。
- 新建配方的 id 和导出目录按配方类型分文件夹。
- 提交后只刷新受影响的配方，不再整类重建。启动和重载时会清掉过期的覆盖标注。
- 可以改温度、线圈、恒星容器、纳米锻炉等配方数据。数量达到万级的 `gtceu:sized` 导出时写成 `gtceu:long`。启用条件使用完整配方 id。
- JSON 加载失败时，会指出非法 id、未知物品或流体、未知配方类型、字段形状错误，以及条件 id 和配方 id 不一致。
- 新增`配方备注`。备注只显示在配方栏，不参与能否执行。添加条件前会先把输入框里还没提交的文字写回草稿。反向标记在保存和同步时保留。

## 配方数据

- 新增物质模块铸造`维度世线碎片`
- 新增超时空装配线`创造维度碎片`
- 新增超时空装配线`万象原核`
- 新增配方类型`原初深空汲取`，以及主世界、下界、末地、月球、火星、水星、金星、谷神星、木卫一、木卫二、木卫三、土卫六、冥王星、恩克拉多斯、巴纳德、冰川、反应堆的汲取配方。
- 宇宙模拟配方把`寰宇模拟单元`当作不消耗输入。
- 原初物质重组的世线电路板配方把`寰宇电路重组单元`当作不消耗输入。

## 自合成仓

- 新增仓室`自合成仓`。合成配方：样板供应器、ME 输入总线、HV 通用电路。
- 放入处理样板后，由这仓自己完成 AE 合成。AE 仍要发配样板原料，配方不消耗这些发配物。
- 发配物退回这仓所在的 AE 网络，随后取消这次合成任务。样板产物不会被造出来。
- 任何面接 ME 线缆都可以连接，不需要多方块主机。
- EAEP 样板上传里，这仓的分组和配方类型显示为`多方块`。
- JEI 多方块结构信息页增加快速编写。结构材料样板只上传到自合成仓。
- 普通配方的快速上传只找星律样板总成。没有对应星律时，样板回到物品栏，不进自合成仓。

## 终极终端

- AE 模式开启时，右击先计算缺口下单。方案就绪后，下一次普通右击只确认下单，不占用施工确认。
- 已提交数量按控制器位置扣减。模拟失败的缺口记下来，不会每次右击都重扫再下同一单。
- 下单之后仍可按现有材料施工，缺材料的位置跳过。

## 星空可请求标签库存输入总成

- 按样板输入做标签匹配，支持物品和流体，不读输出。
- 白名单、黑名单、通配符和 `@模组` 与特大号标签过滤总线相同。
- 不预存材料。配方耗料时直接从 ME 网络抽取。
- 侧栏`可请求`默认开启。库存不足时提交合成请求，产物回到 ME 网络。
- 关闭后只使用网络里已有的库存。已经提交的订单仍会做完。

## 样板副产物

- 终端可以直接请求样板副产物。请求数量按该副产物的单次产量计算，主产物仍会一起产出。
- 指令 `/样板副产物` 切换手中编码样板的标识。放回供应器后生效。
- JEI 另有一颗上传按钮，单独上传一份带副产物标识的样板。原来的快速编写不写这个标识。
- 星律倍率重编码会保留这个标识。副产物不会从 AE 可合成索引里消失。
- 循环容器除不尽，或倍率缓存过期时，不再退回 1 倍样板。AE 按放大后的产物数量下单和显示。

## 原初深空汲取

- 新增引擎模块`原初深空汲取核心`，装在引擎模块位。
- 按模块等级提供并行，电直接从电网取。
- 集气室、大型集气室、虚空聚流反应、虚空流体钻机只产出流体。
- 添加`终极世界碎片高速采集模块`专用于`深空汲取`配方类型
- 深空汲取以采集模块和世界碎片为催化剂。

## 高级电路

- 配置器重开时只认服务器推下来的选择，不再读客户端空槽。已开启的电路不会显示成关闭，数量也不会错。
- 界面增加`全选`和`清空`。

## JEI 收藏

- 收藏判断认等价标签，可替代材料不再误收藏。
- 排除规则只写物品 ID 时，不论 NBT 都排除。写成 `物品ID{SNBT}` 时，ID 相同且 NBT 包含这些键才排除。字符串 `*` 表示该键存在且非空。也接受 `Item.of(...)`。
- 默认排除数据模块，以及带研究 id 的数据球、数据棒。

## 寰宇物品

- 新增`寰宇模拟单元`、`寰宇电路重组单元`。
- `寰宇模拟单元`用于鸿蒙`宇宙模拟`配方：`极高密度量子色动力学爆弹`x64 `寰宇模拟单元`x1(不消耗) + `宇宙素`x102400B 即可运行全2.1g数量产出的高级配方
- `寰宇电路重组单元`用于世线板的增产 大约是原配方的4倍产出 4通用电路⇒16世线电路

## 合成请求

- 材料已经在网络里时，快速请求直接记作满足。不再关掉聚合图，也不再把整单退回旧请求。
