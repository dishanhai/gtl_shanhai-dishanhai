# gt_shanhai 4.1.0

发布日期：`2026 年 10 月 4 日`

## JEI 与样板编码

- 新增 JEI 快速样板编码与商店阶段管理联动。
- 优化星律样板自动上传流程与日志输出。
- 支持原版熔炉配方快速编码为样板。
- 修复快速上传目标重复时的高亮显示。
- 增强 JEI 配方侧边收藏功能，支持按当前配方需求筛选。

## 星律样板总成

- 重构星律样板总成，优化配方类型绑定与跨类型搜索逻辑。
- 增加样板总成与 EnhancedCore 联合工厂的兼容支持。
- 增加模块催化剂槽等 JEI 辅助界面。

## 配方控制

- 新增 Java 配方注册与条件判断能力。
- 新增动态星核剥离器配方注册。
- 增加配方查找规则副本与运行时配方管理。
- 增加配方规则去重与预设自动恢复。
- 增加配方开关持久化，重启后保留启用/禁用状态。

## 商店与界面

- 增加商店阶段、提交任务与阶段预览相关功能。
- 优化商店编辑界面、自动合成确认界面与货币预览。
- 增加商店阶段编辑界面的模糊背景效果。

## 核心兼容

- 增加 EnhancedCore Mixin 配置与配方统计改进。
- 优化多方块预览、配方缓存及相关客户端兼容逻辑。
