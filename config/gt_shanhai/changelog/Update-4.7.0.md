# gt_shanhai 4.7.0

发布日期：`2026 年 10 月 21 日`
此更新贡献者：**dishanhai**——`核心代码贡献者`

接在 4.6.0 后面。商店所有按钮有了按下压感、回弹和点击声，买卖有等待与成交结果，商品编辑器分成五个页签。星律样板总成支持伪神之锻炉的动态产出倍率。修了通配槽串单、电炉样板 ID 匹配，卡单监测和槽位扫描也做了优化。

## 联机兼容

- 商店网络协议升到 7。服务端与客户端必须同为 4.7.0，版本不一致时商店买卖无法正常使用。

## 商店按钮反馈

- 商店里的按钮按下时有压感，松开回弹，点击有音效。不可用的按钮点下去会轻抖并发出低响。
- 详情页的数量 ± 按钮按住连发，越按越快，滴答音高渐升。数量到边界时低响轻抖。× ÷ 一排仍是单击。购物车里的 ± 不连发。
- 确认购买、确认出售按钮点下后显示「处理中…」，服务端回执到了再闪绿、金或红，并播对应音效。点击和键盘 Enter 走同一条路径，带请求号，重复点击不会重复下单。5 秒没有回执，结果提示淡出。本地预检不过的，按钮就地红闪。
- Enter 或小键盘 Enter 等同点确认。按住只算一次。搜索框里或浮层盖着时不下单。
- Esc 先关浮层，再退出搜索框或数量框的焦点，再按一次才关店。确认与 ± 步进按钮悬停有换行说明；等待结果或连发中不弹。
- 设置页新增「减少动效」和「商店音效」两个开关，所有玩家都能打开设置页。没有编辑权的玩家只看到这两项本机显示偏好，不会建立、绘制或提交服务端设置。减少动效开启时不画点击波纹。
- 自动合成确认和自选奖励弹窗用同一套按钮反馈。长文字换行，不截断。页码行和按钮各留位置，页码不再压住按钮。自动合成确认的列表滚轮一次滚 3 行，支持 ↑↓、PageUp、PageDown、Home、End。自选奖励用 ↑↓ 选择并滚进视野，确认后回到商店，按钮显示等待与成交结果。
- 弹窗里的滚动条可以拖动。商店重建时 Enter 还按着，松开前不会下单。
- 购物车批量结算时，SDA 或无限盘类单次使用存储设备数量超过 3 个，会先弹出警告对话框，确认后才结算。

## 商品编辑器

- 「跳转到」改成点按钮挑商品（隐藏商品也能挑），存目标的稳定 ID，目标改名、改称呼都不会断。「别名」改称「称呼」，留空时跳转入口显示商品名称。旧存档里手打的称呼在服务端重载时自动转换并写回。详情页的跳转行显示目标称呼，长名换行。
- 编辑器分成五个页签：商品、价格、限购、奖励、跳转。每页记住自己的滚动位置。
- 行高按内容现算。免费时成本各排自动收起，不留空位。周期限购、限时折扣、提交物品等说明改到框下换行显示，不再越出面板被裁。显示名称独占一行。输入框、槽位、按钮对齐同一条竖线。
- 取消、确认保存移到页脚右下。输入框只在自己那页、整个落在可视区里才显示。点击和滚轮只作用于本页可视区内的行。商品、成本、提交物品与奖励池的格子放不下时自动换行，滚轮统一上下滚动整页，奖励池最多可配置 20 项。
- 阶段提交限制的格子也会换行，超出视口时平滑上下滚动，滚动条可点可拖。修复一格替换成多项后，下一次添加物品会拿到错误数量的问题。
- 按钮、页签、描述大框、数量框的按钮用商店同一套按键反馈。整页滚动条可拖动，点轨道直接跳转。
- 奖励池接管时的商品名、FTBQ 表标题、前置任务标题改为换行，行高跟着长。分类下拉按最长分类名加宽，仍放不下才换行，翻页按实际能放下几行算。
- Esc 一次只收一层：放弃确认框、数量框、描述大框、分类下拉、输入框焦点，最后才回商店。取消或回商店时，草稿和打开时不同，会弹「放弃未保存的修改？」。Esc 继续编辑，Enter 放弃。
- Ctrl+Enter 保存。Ctrl+1 到 Ctrl+5 切页，Ctrl+Tab、Ctrl+Shift+Tab 轮换。页脚左侧显示快捷键提示，放不下就换行，页脚跟着长高。
- 保存前的四项检查（FTBQ 未选表、商品身份为空、成本为空、成本含不存在的物品或流体）不再只发聊天消息。自动切到出错那页，把那一行滚出来，页脚左侧用红字写明原因，保存按钮轻抖并发出失败音。第一次保存失败后，有问题的页签挂红点，改对了就消失。目录已更新时，页脚直接提示重新打开。
- 新商品没选商品时的提示，从「FTBQ表里没有物品类奖励？」改成「还没选商品」。

## 商店选取器

- 多选选取器改为侧栏、网格、已选清单三栏。侧栏可切物品、物品栏、JEI 书签、流体与贴图，并可切换默认、名称、模组、ID 与数量排序；按模组分区后，标题固定在网格顶部，长模组名完整换行。
- 已选清单的名称、模组名和「原格」提示都按宽度换行，行高随内容增长；行内数量框支持精确 long、按住连发和滚轮步进，「全部设为」与清空放在清单顶部。
- 支持左拖连续加入、右拖连续移除、Shift 一组、清单拖曳换序与边缘自动卷动；网格、清单和侧栏都可卷动，滚动条可拖、可点轨道跳转。
- 已选清单每一项下方新增两排快速填数：红色一排减、绿色一排加，步长 1、10、100、1K、10K、100K、1M；减到 1 为止。
- 修复按模组分区时，吸顶的模组标题被滚到下面的物品图标压住、字被盖掉；侧栏的数量改为右对齐，五位数不再被截出栏外，模组名在剩余宽度内换行。
- 商店顶部的分类页签（含购买/出售）加入点击反馈：按下明显压小（缩到 86%）、整格亮成金色并闪一下，松开回弹；切页改到松开时进行。
- 点编辑器里已有的格子打开选择器时，整排的内容都会预填进已选清单，点中的那格为激活项；确认后整排按清单替换，清空再确认即清空这一排。点「+」空格仍从空清单开始。
- 父画面固定在选取器下层绘制，前一页的高层文字不会压住当前面板；保留背景模糊、面板柔影与减少动效下的静态显示。

## 星律样板总成

- 产出倍率支持伪神之锻炉（`gtladditions:forge_of_the_antichrist`）及其子模块。伪神的倍率是 1 到 15 的连续值：工作时逐秒升高，闲置时逐秒回落，只有封顶 15 倍才是静态值。样板按向下取整声明，实际产出是 `floor(数量 × 倍率)`。多报一格，AE 会一直等不到那一份。宿主倍率每变一格，自动重写样板。
- 容器输入（等离子容纳单元、时间膨胀容纳单元等）只按伪神自身倍率放大。枢纽、线程、引力波等叠加层只放大产出。`stellar_forge` 里三条需要空罐的配方，倍率不小于 2 时追加 `倍率 − 1` 个空容器输入。光相莱林结晶器不吃伪神倍率，始终 1 倍。
- 「读宿主」改为每 tick 轮询。宿主倍率连续两次读到同一个新值才会应用，避开模块工作与空闲之间的瞬时跳变。
- 手动输入的倍率不小于 1，没有固定上限。从宿主读取的倍率是多渠道合并结果，可以超过 1000。
- 修复调小每行槽位、每页行数、最大页数后，旧存档里的 `cacheRecipeCount` 比当前槽位数更长，导致方块实体载入失败的问题。载入前先截到当前槽位数。
- 配置页里的槽位提示补充了默认值 10×10×10 = 1000。重启后，已放置的多方块结构也会采用新设置。

## 样板匹配与卡单监测

- 修复通配展开槽串单。展开槽先按已解析的公开配方 ID 比对，不再由库存驱动匹配到别的配方上。
- 样板身份校验改用 accessor 读取 `slot2PatternMap`。读取失败时不再放行。
- 配方 ID 匹配先规范化类型别名。电炉代理接受原版 smelting ID，查不到时回退到原版熔炼配方，修复电炉样板 ID 对不上的问题。
- 显式标记了类型的槽只比对类型字段。类型是推断出来的槽才计算完整内容指纹。
- 样板总成用位集记录已配置样板的槽位，枚举活动槽只遍历有样板的槽。
- 卡单监测按维度、坐标、槽位去重，描述文本拖到触发时才生成。触发前会确认样板仍在原槽。服务器停止时清空队列。
- 倍率配置界面与指南补充提示：倍率变化可能卡住已排队的任务。

## 配方修改器与 IO 表

- 配方修改器的行和标签按两条列线排版，文字按宽度换行，行高随行数增长，不再截断。
- IO 表的标签提示不再限制显示数量，NBT 标签也不再按长度截断，所有相关标签都会列出。
- 配方修改器的标记控件改为由构造参数给出坐标，并支持独立的 Y 坐标，背景绘制跟着自定义的垂直位置。

## 内部调整

- 新增按钮即时反馈核心：`ButtonFeedback` 状态机管按下回弹、去抖、等待和结果闪色，`RepeatCurve` 管按住连发节奏，`UiSoundThrottle` 做音效分频道节流。
- 新增 `ShopDialogUi`、`ShopDialogRows` 和商品编辑器排版函数 `ShopEntryEditLayout`，弹窗和编辑器共用。
- 新增 `ForgeOutputMultiplier`，集中伪神倍率的量化与空容器追加规则。
- `ShopActionPacket` 追加 `requestId`（0 表示不要回执），带请求号的买卖由 `ShopActionResultPacket` 回执。
