# gt_shanhai 4.9.0

发布日期：`2026 年 11 月 7 日`
此更新贡献者：**dishanhai**——`核心代码贡献者`、**lycc193bp**——`issues #13 / #27 / #31` 反馈者并提出改进建议、**AutumnRainLF**——`issues #28` 反馈者、**yuanmiaomia**——`issues #29` 反馈者

备注：`奈亚拉托提普之触`的结构来源是`GT-Odyssey`，其中结构由**犰狳** & **疏影**提供。`奈亚拉托提普之回响`为自建结构，由 **dishanhai** 提供。

接在 4.8.0 后面。原初机器改为整机共享并行的多线程调度，配套新增配方线程仓、优先级调度与 Jade 独立线程面板。引力波广播从奈亚拉托提普之触拆到新多方块「奈亚拉托提普之回响」，并加上归墟链接模块、奇迹物质与奇迹之流；天界虹吸矩阵重做为 13 档物质流与零点能注入。归墟视界补齐表面闪电、深空背景与差速吸积盘，玻璃 AR 投影现可直接点击或滚轮翻页。界面底层抽成独立库 `SH-Better-UI`，带来星界玻璃与透明玻璃主题，单人进档也加上了异步加载与玻璃面板进度页。商店补齐搜索联想补全、资源筛选、全局/个人禁用开关、个人限购额度与余额飘字。

## 联机兼容

- 网络协议升到 16（4.8.0 为 12）。服务端与客户端必须同为 4.9.0，版本不一致时进不了服务器。

## 原初多线程调度与配方线程仓

- 原初主机与模块改为整机共享并行的多线程调度（`PrimordialThreadScheduler`），按线程预留份额分配并行度；主机与模块均补上多线程倍率物品槽位，样板缓存推送成功后会自动唤醒所属原初主机。
- 新增「配方线程仓」部件，提供独立配方批次容量（仓内物品不参与配方输入）；维护舱同步加上独立配方批次开关与专属配置页签。
- 引入配方线程优先级调度（`RecipeThreadPriority`）：按预估耗时与能耗排序，优先跑长耗时或虚拟候选配方，且无法启动的长配方不会堵死短配方。
- Jade 新增原初左侧独立线程面板与配方线程仓信息展示，分页查看在途批次、线程容量、能耗与产物；补上真实配方身份追踪，不再显示 `DUMMY` 配方，也不会让样板 NBT 污染全局配方。
- 修复原初模块无线能耗与产能的正负号反转问题，以及挂载湮灭核心时复制配方丢失无线能源、并行度与超频等级的问题。

## 奈亚拉托提普之回响、天界虹吸与新物质

- 新增「奈亚拉托提普之回响」多方块机器（13×12×15）、回响链接模块与「无貌者之音」配方；原先在「奈亚拉托提普之触」上的引力波广播迁至此机器，支持无线配方广播且不会自我循环接收。
- 新增「归墟奈亚拉托提普链接模块」，建立黑日物质通道与光晕渲染；另增仅供结构观赏的「奈亚拉托提普之触结构预览机器」。
- 新增物品与流体「奇迹物质」与「奇迹之流」，配套补上物质锻造与物质流冷凝配方。
- 重构「天界虹吸矩阵」并行逻辑：去掉旧的 3 档加成，改为 13 种物质流与零点能档位，自动挑仓内最高档位流体消耗，最高支持 `5,242,880` 并行，并在 UI 与悬浮提示里实时列出注入状态。
- 移除已废弃的综合组装车间、集成装配矩阵、空间缩放仪与中子框架。

## 归墟视界特效与 AR 触控交互

- 归墟玻璃 AR 投影支持射线触控与滚轮交互：对着投影点击或滚轮即可切换信息页与模块页，支持手动锁定分页，并拦截左键攻击以免误碎玻璃；同时修好不同朝向下墙面帧的原点与旋转角计算。
- 归墟结构表面新增电弧闪电（`GuixuStructureLightning` / `GuixuAccretionLightning`）、局部深空背景幕与带黑洞投影遮蔽的三维星场；吸积盘升级为开普勒差速旋转、双周期湍流与相对论多普勒增亮。
- 强化山海不稳定特效的峰值电弧与碎片数量，加入不透明黑日核心渲染层，并将光晕延后到方块实体之后绘制，不再被远处黑核裁掉。

## 星界玻璃 UI 与异步载入画面

- 提取 UI 底层至独立库 `SH-Better-UI`（1.0.3），新增「星界玻璃」主题（支持深蓝与中性烟灰配色）与「透明玻璃」外观开关，样板缓冲器、维护舱、远程终端与提示框统一换用星界玻璃材质。
- 新增「山海载入动画」与单人世界数据异步加载（`ShanhaiLoadingAsync`）：数据包、注册表与配方改走专用串行线程，JEI 索引阶段自动补帧保持窗口响应，加载页与性能分析报告同步换用透明玻璃面板（含兼容回退开关）。

## 商店系统

- 搜索框换用玻璃模糊底与青色亮边，新增最多 5 项商品联想与框内补全（支持名称、ID、前缀与拼音匹配，上下键与鼠标点选），右键可一键清空。
- 新增资源筛选器，可按商品或成本所含的物品、流体及 FTBQ 奖励表内容过滤目录。
- 新增商店全局（OP）与个人禁用开关（可在初始化向导与主界面覆盖层切换），禁用期间自动拦截银行命令、兑换与自动合成。
- 限购次数由全服共享改为按玩家个人剩余额度（永久额度）独立计算并实时同步（`issues #27`），余额变动时带三槽位错峰飘字动画；底部新增两行自动轮播小提示，顶部通知弹窗精简为方框磨砂样式，长名称支持像素级滚动与自动分页。

## 星律诊断、指南与综合修复

- 星律卡死监控接入跨配方线程容量、占用与聚合批次阻塞评估；终端报告新增告警「忽略/解除」按钮，并持续追踪 AE 订单直到完成或取消。
- 重构 JEI 快速编码报错收集，全部硬编码诊断与等待提示改为多语言翻译键。
- GuideME 新增《归墟视界总览》《归墟视界枢核》《彭罗斯遏制场》《超维度归墟连结》《配方线程仓》等指南，物质模块等级表补齐 Lv.1–Lv.17 配方等级列（`issues #13 / #33`）。
- 修复量子合成节点在区块卸载、AE 节点已销毁后仍更新连接面导致服务端崩溃的问题（`issues #28`）。
- 修复 UEV 阶段升维物质模块前置材料「始世线创世胚」的配方循环依赖错误（`issues #29`），以及 16 级纯水配方的命名空间错误。
- 修复开屏更新日志界面在内容区外点击会点穿触发底层链接的问题（`issues #31`），以及 JEI 重建时去重缓存残留、机壳方块注册时机晚于机器的问题。
