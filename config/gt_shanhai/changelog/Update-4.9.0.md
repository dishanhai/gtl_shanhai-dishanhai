# gt_shanhai 4.9.0

发布日期：`2026 年 11 月 7 日`
此更新贡献者：**dishanhai**——`核心代码贡献者`、**lycc193bp**——`issues #13 / #27 / #31` 反馈者并提出改进建议、**AutumnRainLF**——`issues #28` 反馈者、**yuanmiaomia**——`issues #29` 反馈者

备注：`奈亚拉托提普之触`的结构来源是`GT-Odyssey`，其中结构由**犰狳** & **疏影**提供。`奈亚拉托提普之回响`为自建结构，由 **dishanhai** 提供。

本次更新承接 4.8.0。原初机器改为整机共享并行的多线程调度，配套新增配方线程仓、优先级调度与 Jade 独立线程面板。新增原生「星律云端样板库核心」与「星律云端样板库 AE 核心」，采用烟色玻璃交互，支持同一 AE 网络中的星律按主机配方类型租用样板原件。引力波广播从「奈亚拉托提普之触」迁至新多方块「奈亚拉托提普之回响」，并加入归墟奈亚拉托提普链接模块、奇迹物质与奇迹之流。天界星云零点虹吸枢纽扩展为物质流与真空零点能共 13 档注入。归墟视界补齐表面闪电、深空背景与差速吸积盘，玻璃 AR 投影现可直接点击或滚动鼠标滚轮翻页。界面底层抽成独立库 `SH-Better-UI`，带来星界玻璃与透明玻璃主题，单人世界加载也加入了异步处理与玻璃面板进度页。商店补齐搜索联想补全、资源筛选、全局/个人禁用开关、个人限购额度与余额飘字。

## 联机兼容

- 网络协议升级至 16（4.8.0 为 12）。客户端与服务端需使用相同协议版本，建议统一更新至 4.9.0。

## 星律云端样板库与玻璃交互

- 新增原生「星律云端样板库核心」（15×11×17 多方块）与「星律云端样板库 AE 核心」，集中保管加工样板与星律通配样板原件。结构中任意一个铱强化机械方块位置必须替换为 AE 核心，绑定玩家须与库主一致。结构成形且 AE 核心接入网络后，同一 AE 网络中的星律可按主机配方类型自动拉取样板。
- 支持样板租约、排空撤回与拆机恢复。使用中的样板请求取回后会先停止接收新任务，待星律排空在途材料并释放租约后即可取回原件。拆机时若有未结清云端状态，会封装为「星律云端恢复元件包」。在原位置放置空闲的星律样板总成，手持恢复元件包右键交回云端恢复数据，重新接入原样板库后继续排空并释放租约。
- 样板库主界面、星律云端设置页与 AE 核心界面统一采用烟色玻璃控件与同步回执机制：搜索、配方类型筛选、分页与原件存取槽常驻，配方详情与玩家授权面板可独立折叠展开；支持 Shift 快捷上传/取回，操作反馈严格配对服务端回执，超时仅刷新状态而不重复提交。

## 原初多线程调度与配方线程仓

- 原初主机与模块改为整机共享并行的多线程调度（`PrimordialThreadScheduler`），按线程预留份额分配并行度；主机与模块均补上多线程倍率物品槽位，样板缓存推送成功后会自动唤醒所属原初主机。
- 新增「配方线程仓」部件，提供独立配方批次容量（仓内物品不参与配方输入）。终焉聚合枢纽同步加上独立配方批次开关与支持滚动的专属配置页签。
- 引入配方线程优先级调度（`RecipeThreadPriority`），根据能耗、并行与功率等条件估算加工耗时，优先尝试耗时较长的候选配方，启动失败后继续尝试后续候选。
- Jade 新增原初左侧独立线程面板与配方线程仓信息展示，分页查看在途批次、线程容量、能耗与产物；补上真实配方身份追踪，不再显示 `DUMMY` 配方，也不会让样板 NBT 污染全局配方。
- 修复原初模块无线能耗与产能的正负号反转问题，以及挂载湮灭核心时复制配方丢失无线能源、并行度与超频等级的问题。

## 奈亚拉托提普之回响、天界星云零点虹吸枢纽与新物质

- 新增「奈亚拉托提普之回响」多方块机器（13×12×15）、「奈亚回响远程链接模块」与「无貌者之音」配方。原先在「奈亚拉托提普之触」上的引力波广播迁至此机器，支持无线配方广播且不会自我循环接收。
- 新增「归墟奈亚拉托提普链接模块」，建立黑日物质通道与光晕渲染（16×16、8 帧动态材质）。「奈亚拉托提普之触」可处理量子化现实重构与铸币工厂配方，由自身仓口供能供料，可独立运行或连接归墟共享增益。
- 新增物品与流体「奇迹物质」与「奇迹之流」，配套补上物质锻造与物质流冷凝配方。
- 扩展「天界星云零点虹吸枢纽」的流体注入档位，保留旧档位的并行数值，增加至 12 种物质流与真空零点能，共 13 档。未注入时为 256 并行，每 5 刻消耗 250 mB 当前可用的最高档流体，最高支持 `5,242,880` 并行，并在 UI 中显示当前注入状态、在悬浮提示中列出各档并行数值。
- 移除已废弃的综合组装车间、集成装配矩阵、空间缩放仪与中子素框架。

## 归墟视界特效与 AR 触控交互

- 归墟玻璃 AR 投影支持射线触控与滚轮交互：对着投影点击或滚轮即可切换信息页与模块页，支持手动锁定分页，并拦截左键攻击以免误碎玻璃；同时修好不同朝向下墙面帧的原点与旋转角计算。
- 归墟结构表面新增电弧闪电（`GuixuStructureLightning` / `GuixuAccretionLightning`）、局部深空背景幕与带黑洞投影遮蔽的三维星场；吸积盘升级为开普勒差速旋转、双周期湍流与相对论多普勒增亮。
- 强化山海不稳定特效的峰值电弧与碎片数量，加入不透明黑日核心渲染层，并将光晕延后到方块实体之后绘制，不再被远处黑核裁掉。

## 星界玻璃 UI 与异步载入画面

- 提取 UI 底层至独立库 `SH-Better-UI`（1.0.3），新增「星界玻璃」主题（支持深蓝与中性烟灰配色）与「透明玻璃」外观开关，样板缓冲器、终焉聚合枢纽、FTBQ AE 自动提交器、远程终端与提示框统一换用星界玻璃材质，并适配 GTCEu/LDLib 流体槽。
- 新增「山海载入动画」与单人世界数据异步加载（`ShanhaiLoadingAsync`）：数据包、注册表与配方改走专用串行线程，JEI 索引阶段自动补帧保持窗口响应，加载页与性能分析报告同步换用透明玻璃面板（含兼容回退开关）。

## 商店系统

- 搜索框换用玻璃模糊底与青色亮边，新增商品联想与框内补全（支持名称、ID、前缀与拼音匹配，上下键与鼠标点选），右键可一键清空；选择器与设置/欢迎页同步接入主题与高斯模糊。
- 新增资源筛选器，可按商品或成本所含的物品、流体及 FTBQ 奖励表内容过滤目录。
- 新增商店全局（OP）与个人禁用开关（可在初始化向导与主界面覆盖层切换），禁用期间自动拦截银行命令、兑换与自动合成。
- 限购次数由全服共享改为按玩家个人剩余额度（永久额度）独立计算并实时同步（`issues #27`），余额变动时带三槽位错峰飘字动画；底部新增两行自动轮播小提示，顶部通知弹窗精简为方框磨砂样式，长名称支持像素级滚动与自动分页。

## 星律诊断、指南与综合修复

- 星律卡死监控接入跨配方线程容量、占用与聚合批次阻塞评估；终端报告新增告警「忽略/解除」按钮，并持续追踪 AE 订单直到完成或取消。
- JEI 快速编码新增对原版锻造台与切石机配方的支持（复用 AE2 分子装配样板并校验精确配方 ID），同时支持一键上传云端库。相关诊断与等待提示改为多语言翻译键。
- FTBQ AE 自动提交器重构为持久化奖励回网队列，妥善处理满网、部分写入与拆装存档，收紧队伍、玩家与仅合成任务校验，并升级玻璃界面与完整状态提示。
- 配方编辑器分离冲突校验与原始快照基准，改用完整 JSON 的 SHA-256 指纹（兼容旧指纹）；配方广播与登录补发改为 64 条分批同步，避免长列表误标删除。
- 补齐终焉聚合枢纽在全体工作机上的材料仓准入与计数判定（借普通 I/O 分支成形，不挤占材料仓配额），修复其绕过温度检查时污染全局配方的问题。
- GuideME 新增《归墟视界与遏制场》《归墟视界枢核》《归墟彭罗斯黑洞遏制场》《归墟超维度链接模块》《配方线程仓》等指南，物质模块等级表补齐 Lv.1–Lv.17 配方等级列（`issues #13 / #33`）。
- 修复量子计算机节点在区块卸载、AE 节点已销毁后仍更新连接面导致服务端崩溃的问题（`issues #28`）。
- 修复 UEV 阶段升维物质模块前置材料「始世线创世胚」的配方循环依赖错误（`issues #29`），以及 16 级纯水配方的命名空间错误。
- 修复开屏更新日志界面在内容区外点击会点穿触发底层链接的问题（`issues #31`），以及 JEI 重建时去重缓存残留、机壳方块注册时机晚于机器的问题。
